Your voice agent should remember the caller.

Retell charges for per-contact call memory. callrecall-ai does it free and local: after every call it writes a structured brief — preferences, facts, open threads, resolved items — and injects it when they call back. PII redaction on by default.

Drop it into Pipecat

One processor between your user aggregator and the LLM — the slot the ecosystem already uses.

from callrecall import CallRecallMemory
from callrecall.adapters import CallRecallPipecat

mem = CallRecallMemory()  # ~/.callrecall/memory.json
recall = CallRecallPipecat(mem, contact_id_fn=lambda f: f.caller_phone)

pipeline = Pipeline([
    transport.input(), stt, user_aggregator,
    recall.processor(),   # <-- memory goes here
    llm, assistant_aggregator, tts, transport.output(),
])
recall.on_call_end(caller_phone, transcript)  # when the call ends

API

MethodWhat it does

brief(contact_id)The structured brief, or None for new callers
context_block(contact_id)Brief rendered as system-prompt text for injection
skippable(contact_id, steps)Flow steps memory already covers (Retell's “skip this node”)
