Self-hosted voice-agent memory · MIT · zero cloud

Give your voice agent a memory in five minutes.

Retell charges for per-contact call memory. callrecall-ai does it free and local: after every call it writes a structured brief — preferences, facts, open threads, resolved items — and injects it when the caller rings back. PII redaction is on by default.

STEP 1

Install

Zero runtime dependencies. Python ≥ 3.9.

STEP 2

Record the call

record_call() extracts a brief from the transcript and appends it to one JSON file.

STEP 3

Inject on callback

context_block() renders the brief as system-prompt text at session start.

Integration

Drop it into Pipecat

One processor between your user aggregator and the LLM — the slot the ecosystem already uses.

pipeline.py
from callrecall import CallRecallMemory
from callrecall.adapters import CallRecallPipecat

mem = CallRecallMemory()  # ~/.callrecall/memory.json
recall = CallRecallPipecat(mem, contact_id_fn=lambda f: f.caller_phone)

pipeline = Pipeline([
    transport.input(), stt, user_aggregator,
    recall.processor(),   # <-- memory goes here
    llm, assistant_aggregator, tts, transport.output(),
])
recall.on_call_end(caller_phone, transcript)  # when the call ends

API

Seven methods. The whole surface.

MethodWhat it does
record_call(contact_id, transcript, ...)Extract a finished call into the contact's brief
brief(contact_id)The structured brief, or None for new callers
context_block(contact_id)Brief rendered as system-prompt text for injection
skippable(contact_id, steps)Flow steps memory already covers (Retell's “skip this node”)
backfill(contact_id, transcripts)Build a brief from a pile of old transcripts
search(query)Keyword search across all briefs
forget(contact_id)Delete a brief entirely
